# Tally 
A personal finance assistant that helps you think through money decisions instead of simply telling you what to do 

## What it does
- Finds patterns in your spending, saving and income history
- Suggests options with assumptions and ranges
- Helps you map out and keep track of anything financially, bills to be paid, investments, incomes, spending and saving
- A chat assistant to help you as a guide during decision making

## Status
Work in progress. Currently in phase 0: a command-line version that saves a transcation to JSON

## Tech stack
Python, Flask, SQLite, pandas, scikit-learn, plain JavaScript, an LLM API
